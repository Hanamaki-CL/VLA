# 版本与交付范围

## 1.0.0 源码版

本版本围绕单臂 LIBERO 仿真实验提供源码与使用入口，包含以下交付内容：

| 交付项 | 内容 |
| --- | --- |
| 数据处理 | 任务筛选、episode 划分、独立统计、数据来源与版本记录 |
| 策略接入 | SmolVLA 加载、图像与状态适配、训练统计预处理和动作后处理 |
| 训练工具 | 目标 GPU 配置、LeRobot trainer 启动、配置和数据来源记录 |
| 仿真执行 | LIBERO 适配、动作块滚动执行、时效和数值约束、有限重试 |
| 实验管理 | prepare → train → evaluate 编排、配置快照、阶段日志、中断状态 |
| 结果交付 | JSON、CSV、离线 HTML、可选双视角 MP4 |
| 工程支持 | 可安装 Python 包、命令参考、架构文档、测试代码、托管 CI |
| ROS 2 示例 | 动作提案格式与时效校验，返回校验回执 |

## 验证口径

源码版本与模型实验分开管理：

- 核心代码的自动化检查结果以 [GitHub Actions](https://github.com/Hanamaki-CL/VLA/actions/workflows/ci.yml) 对应提交为准。CPU CI 包含单元测试、mock 视频与报告流程、wheel/sdist 构建和安装入口检查。
- SmolVLA 模型加载、GPU 微调、LIBERO/EGL 闭环运行需要在目标环境单独执行。仓库不附带这些步骤的实测结果，CPU CI 不能代替它们。
- 性能数据只能由实际运行的 `episodes.jsonl` 和 manifest 生成。仓库不预填成功率、吞吐或性能提升数字。

## 版本边界

本版本以公开单臂仿真任务为对象。模型结构、预训练权重与训练循环使用上游实现；自有代码负责数据、接口、执行和实验管理。

真机闭环、Flexiv 驱动、双臂协作、配餐专用资产和称重配重属于独立扩展方向。ROS 2 消息校验示例不提供真机执行能力。

同步推理的超时检查在调用返回后执行，不保证硬实时中断。训练中断恢复使用上游工具；流水线不对已有目录进行覆盖或自动续跑。
