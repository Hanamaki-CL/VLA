# 项目状态

当前版本：0.1.0。阶段：集成开发。

## 已提交实现

| 模块 | 范围 |
| --- | --- |
| 数据 | 任务筛选、episode 划分、LeRobot 数据集导出、来源记录 |
| 策略 | SmolVLA 加载、观测适配、保存的预处理/后处理管线 |
| 执行 | 动作块前缀队列、数值和时效检查、有限场景重试 |
| 评估 | LIBERO 接口、逐回合日志、成功率和延迟统计 |
| 接口示例 | ROS 2 动作提案校验与回执 |

## 验证进度

单元测试、目标环境安装、模型加载、训练和仿真评估均待执行验证。当前没有发布训练权重、实测指标或演示视频。

接口按 LeRobot 0.4.3 源码核对，已处理数据导出时的 CHW/HWC 转换及源数据版本缓存隔离。静态审阅不替代运行验证。

## 后续工作

- 在目标 GPU 环境完成依赖安装、模型前向/反向和 EGL 渲染验证。
- 完成三个 LIBERO 任务的训练与闭环评估，归档配置、数据版本和逐回合结果。
- 比较不同动作执行步数下的成功率和推理开销。
- 扩展配餐任务数据与场景，再评估真实机械臂适配。

真机控制、双臂协作、称重配重和视频录制不在当前实现范围内。
