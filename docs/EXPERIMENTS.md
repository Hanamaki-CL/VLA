# 实验协议与结果记录

当前没有已运行结果。本文件定义未来实验，而不是展示已有成绩。

## 主实验

使用 `libero_object` 中 task IDs `[0,1,2]`，每个任务 20 个不同的官方初始状态，seed 为 42 + 初始状态 ID。记录真实任务文本，不能将官方任务重命名为自主构建的配餐任务。

默认执行 horizon=10，最多 280 步，reset retries=0。这个 60 回合协议是自定义工程实验，不能直接比较论文的完整套件均值。初始状态与公开训练示教可能存在重叠，不能称为已证明的未见场景泛化。

## 推荐消融

| 实验 | 唯一主要变量 | 保持不变 |
| --- | --- | --- |
| E1 | horizon=1、5、10 | checkpoint、任务、种子、步数限制 |
| E2 | 训练步数对应的不同 checkpoint | 数据划分、评估条件 |
| E3 | retries=0 或 1 | checkpoint、初始场景、horizon |
| E4（后续） | 原始指令 / 受控改写 / 同场景不同目标 | 同一场景，其余参数 |

E1 可通过修改评估 JSON 执行。E2 通过替换 checkpoint 执行。E3 是重置重试实验，不声称实现了原地抓取恢复。E4 尚无自动化入口，需要另行设计语义等价与目标切换对照；删除语言输入的结果也不能单独证明语言理解。

## 统计规则

1. 一个任务、初始状态与随机种子的组合只计一个场景。重复记录显式拒绝。
2. 首次成功率分母为所有完成评估的场景；最终成功率允许包括重置重试，但不改变分母。
3. `complete=false` 或 manifest 为 `aborted` 的结果必须标为部分运行。基础设施错误不伪装成普通任务失败。
4. 同时报告成功数/总数及 Wilson 95% 区间；60 个场景的差异不能只比较小数点后的数字。
5. 延迟包括实际 GPU 结果回传；模型加载时间不包含在回合推理延迟中。仿真一步耗时不是机械臂伺服延迟。
6. mock-only 输出只能用于工程联调。
